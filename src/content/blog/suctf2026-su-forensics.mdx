## Description

Misc

During a raid on a cross-border telecom fraud gang, police apprehended a suspect. At the moment of arrest, he was editing a "secret rule" in a new tab of Windows Notepad. The page was blank, indicating unsaved changes. When police entered, he quickly pressed a few keys, seemingly deleting crucial content. As a forensic expert, we are providing you with the system disk image file of this host.

Please answer the following questions:

1. When was the device last shut down? Please provide your answer in UTC+8 timezone. (`YYYY/MM/DDTHH:MM:SS`)
2. The MD5 hash (32-bit lowercase) of the deleted content in Notepad.
3. What is the first key?
4. The session ID and time used to obtain the second key. Please provide your answer in UTC+8 timezone. Time format: `YYYY/MM/DDTHH:MM:SS`. Connect the two answers with an underscore.
5. The content of the final usable key.
6. The time for the Ollama client's `no such host` message. Format: `YYYY/MM/DDTHH:MM:SS`.
7. To ensure the local model outputs a key in a fixed format, the suspect obtained this prompt in a specific session. Please provide the message ID that obtained this prompt.

## Summary

This challenge gives an AD1 forensic image, `abc.ad1`, packed inside `abc.7z`. The workflow is straightforward:

1. Verify the archive hash.
2. List the AD1 contents.
3. Extract the interesting artifacts.
4. Reconstruct seven answers from Windows registry, Notepad tab-state, uTools clipboard, Ollama logs, and Cherry Studio IndexedDB.

I used two small helper scripts during the solve.

```python
from pyad1 import AD1
import sys

def walk(item, prefix=""):
    name = item.name
    path = f"{prefix}/{name}" if prefix else name
    print(path)
    for child in item.children:
        walk(child, path)

ad1 = AD1(sys.argv[1])
for root in ad1.root_items:
    walk(root)
```

```python
from pyad1 import AD1
from pathlib import Path
import sys

def walk_extract(item, outdir, prefix=""):
    name = item.name
    rel = f"{prefix}/{name}" if prefix else name
    dst = Path(outdir) / rel

    if item.is_file:
        dst.parent.mkdir(parents=True, exist_ok=True)
        with open(dst, "wb") as f:
            f.write(item.read())
    else:
        dst.mkdir(parents=True, exist_ok=True)
        for child in item.children:
            walk_extract(child, outdir, rel)

ad1 = AD1(sys.argv[1])
outdir = sys.argv[2] if len(sys.argv) > 2 else "extracted_ad1"
for root in ad1.root_items:
    walk_extract(root, outdir)
```

## Q3

Question:

> What is the first key?

This answer comes from uTools clipboard history, not from the visible Ollama example output.

Original artifacts in AD1:

- `Users\Administrator\AppData\Roaming\uTools\clipboard-data\...`
- `Users\Administrator\AppData\Local\Programs\utools\resources\app.asar`
- `Windows\System32\config\SOFTWARE`

Extracted files used:

- `utools_clip_1772700955558.bin`
- `utools_clip_1772701170720.bin`
- `utools_app.asar`
- `win32-x64.node`
- `extracted_SOFTWARE`

How to decrypt the uTools clipboard:

1. Reverse `utools_app.asar` and `win32-x64.node`.
2. Find the clipboard encryption logic:

```jsx
createCipheriv('aes-256-cbc', getLocalSecretKey(), 'UTOOLS0123456789');
```

3. Recover `MachineGuid` from `SOFTWARE`:

```text
dfa96070-797f-4b50-bb3e-d478d5c44179
```

4. Recover the native salts from `win32-x64.node`:

```text
H22`OB~6i{A{TXqIqPEg
|Wea6ywQQ`1q>_QyY2f1
```

5. Compute:

```text
MD5("H22`OB~6i{A{TXqIqPEg" + MachineGuid + "|Wea6ywQQ`1q>_QyY2f1")
= 5a569f2670ad9d9765df113e1417083f
```

6. Use `AES-256-CBC`, key = ASCII string `5a569f2670ad9d9765df113e1417083f`, IV = `UTOOLS0123456789`.
7. Each line in the clipboard files is hex-encoded ciphertext, so decrypt with `bytes.fromhex(line)`.

Recovered plaintext from `utools_clip_1772700955558.bin`:

- `zQt$d3!GIS9l.aR@7ELN`
- `A9!fK2@pL4#tM6$wN8%yR1^uD3&hJ5*Z`
- Note and rule fragments

The accepted first key is:

```text
zQt$d3!GIS9l.aR@7ELN
```

```text
4dE23eFgH7kLmNpOqRstUvWxYz012345678901234567890123456789
```

This is `key2`.
